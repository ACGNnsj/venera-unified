# Android TV Alpha 实验（#131）

TV 版在 `main` 内以 Gradle flavor 的形式存在（`mobile` / `tv`），代码与手机版共用；TV 包是实验构建，不等于真机验收，也不表示低内存崩溃已解决。

## 身份与安装隔离

| 项目 | 普通 Android | TV Alpha |
|---|---|---|
| Flavor | `mobile`（默认） | `tv` |
| 包名 | `io.github.venera.unified` | `io.github.venera.unified.tv` |
| 启动器 | Venera Unified | Venera Unified TV Alpha，带 leanback 入口与横幅 |
| 方向 | 沿用应用设置 | 固定横屏 |
| 应用更新 | 沿用正式版渠道 | 不查询应用更新（漫画源更新不受影响） |
| 数据 | 原沙盒 | 独立沙盒，不读取、迁移或删除手机版数据 |

两个包可以共存。回退可卸载 TV 包，不影响手机版沙盒；TV 包数据应提前备份。不要同时从两套应用向同一 WebDAV 备份位置写入。

## 当前交互边界

- 主界面使用侧栏、可见焦点、安全边距和至少 1.1 倍字号。方向键移动焦点，确定／手柄 A 激活，返回／手柄 B 返回；支持菜单键的遥控器可打开控件上下文菜单。不要求鼠标悬停。
- 阅读画面获得焦点时，方向键交给阅读器翻页／滚动，确定打开菜单；菜单打开后方向键仅移动控件焦点，不再触发背景翻页。
- 返回优先收起阅读菜单，再走原有的保存／资源释放流程退出。失焦、菜单打开或切后台会取消持续按键。
- 这是复用现有界面的第一轮适配，不是十英尺界面重设计。网页登录、验证码、文件选择器、第三方页面和细粒度手势可能仍需输入设备。

## 低内存策略

TV 默认开启「设置 → 阅读器 → TV 低内存模式」，仅存本机，不进导出备份或 WebDAV：

- 单页画廊、单页显示、1 页预加载，暂停自动阅读模式识别；不改写已有阅读配置，关闭开关后恢复。
- 图片缓存上限 64 MiB，先于异步内存查询应用。
- 解码约束为最多 `1920 × 1080` 像素且最长边 8192，不放大小图，不修改原始文件。
- 长条图与放大细节可能明显变糊；64 MiB 不是进程总内存上限，也不是不会 OOM 的保证。

## 构建与产物

```
flutter build apk --release --flavor tv --target-platform android-arm64
# 产物: build/app/outputs/flutter-apk/app-tv-release.apk
```

TV 包使用独立的 `android/app/src/tv/AndroidManifest.xml` 覆盖（leanback 启动项、横幅、横屏），release 与 debug 均可构建。CI 目前只验证共用代码；TV 构建尚未纳入自动门禁。
