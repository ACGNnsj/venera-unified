### 新增

- 在“关于”中新增赞助者名单页面，支持置顶赞助、当前赞助者和历史赞助者分区展示。

### 变更

- 赞助者名单改用结构化数据统一生成应用数据、GitHub 名单和 README 置顶宣传区，并增加格式校验、确定性检查及旧版数据兼容。
- 赞助状态改由爱发电 API 定时同步，自动识别当前方案、到期状态、历史档位和符合条件的一次性赞助；同步失败时保留上次成功名单。

### 修复

- 修复桌面端标题栏品牌标识在侧栏折叠时仍显示文字并穿过分割线的问题；折叠状态下仅显示应用 logo。
- 修复开启不可变 GitHub Release 后，预发布构建可能先发布空 Release 导致资产上传失败的问题。
- 修复 Windows 升级后可能无法读取旧应用身份目录中本地数据的问题；迁移过程现在兼容多代目录，并且不会因新目录已生成日志等文件而跳过缺失数据。
- 修复应用配置写入中断或内容异常时直接删除 `appdata.json` 的问题；配置文件现在采用原子替换并保留备份，启动时可从备份或同步数据恢复，同时保留损坏文件用于排查。
- 修复稳定版可能收到预发布版本更新提示的问题；更新检查现在只使用已发布的 GitHub Release，稳定版忽略草稿和预发布，RC 版本才会跟踪后续预发布。

### 文档

- 更新 Windows 安装与分发说明，明确 winget 已正式可用，并补充安装、升级、源刷新、审核延迟和便携版限制。
- 完善赞助档位、永久鸣谢、置顶宣传、排序规则和维护边界说明，并在项目介绍下方恢复漫画源分离声明。
- 新增完整英文 README，并在中英文首页增加语言切换、GitHub 主仓库和 Gitee 国内镜像入口。
