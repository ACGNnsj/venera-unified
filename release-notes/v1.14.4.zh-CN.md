### 新增

- WebDAV 漫画库支持通过 `metadata.json` 标记深层目录中的漫画根目录；根目录的直接子目录会作为章节，并使用相对路径作为漫画 ID，避免分类目录下的同名漫画互相覆盖。

### 维护

- 修复 Windows Inno Setup 安装包遗漏 Flutter 原生插件 DLL 的问题；现在会完整收集 Release 目录，避免 `super_native_extensions_plugin.dll` 等新增运行库未随安装包发布。
- 收束漫画展示组件的业务依赖：收藏、历史、本地漫画封面和收藏页显示偏好改由运行时注入，并增加结构检查防止展示层重新依赖具体业务管理器。
- 收束漫画源功能域依赖：阅读历史元数据契约下沉到基础层，数据同步与 WebDAV 附加源改由运行时注入，并增加结构检查防止反向依赖回退。
- 更新 `share_plus` 至 12.0.2，包含 iOS 分享流程的稳定性修复。
- 预处理 Dio 5.11.0 的拦截器兼容性，避免自定义拦截器在异常路径中因缺少 Dio 内部调用链而导致请求挂起。
- 更新 `battery_plus` 至 7.1.1，并通过 Android release 与 macOS DMG 构建验证。
